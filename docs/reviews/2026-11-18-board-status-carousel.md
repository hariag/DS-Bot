# 看板状态视图：任务卡 3D 焦点切换

- 日期：2026-11-18
- 基准：`main` @ `57bfaadd`（看板状态列精简后）
- 问题：按状态分列后工作流仍有多列，横向铺满一页；希望默认只展开三张卡，左右两侧只露出卡片的一部分，点击卡片时把它和左右相邻卡一起展开，类似 3D 卡片切换。

## 1. 交互模型

```
[状态 chip：起草中 0 | 待准备 6 | 等待中 0 | 进行中 1 | 待验收 1 | 完成 0 | 已取消 0]
[当前状态的 3D 卡片区]
   左侧相邻任务卡（局部） | 当前任务卡（居中放大、高亮） | 右侧相邻任务卡（局部）
   ‹/› 切换卡片        ← 1 / 6 →        前移/后移
[当前状态列头部：状态名、数量、列菜单、加卡]
```

- **状态 chip**：所有状态始终可点，显示数量；点击直接跳到该状态。支持 `ArrowLeft` / `ArrowRight` / `Home` / `End`；窄屏时 chip 条横向滚动，当前状态自动滚入可视区。
- **3D 卡片区展示的是当前状态的真实任务卡**，不是额外的状态摘要卡：
  - 当前任务卡居中放大，保留卡片原有的标题、类型、标签、截止日期、负责人、评论/附件计数、封面等；
  - 左右相邻任务卡使用同一张真实卡片，缩放、旋转、降低不透明度并只露出局部；
  - 点击左右卡切换焦点（不打开详情）；点击中间卡打开原有任务详情弹窗；
  - 卡片数量超过 3 张时，只渲染当前、左、右三张，用左右箭头逐张切换；底部显示 `当前 / 总数`。其余卡片通过箭头到达，不会一次铺满。
- **卡片排序**：底部「← / →」按钮把当前卡在列内前移/后移，调用原有 reorder 命令；3D 布局下不再依赖拖到另一张卡上排序。
- **拖动**：把当前卡拖到上方状态 chip 上，按原状态机执行 submit / schedule / restore / cancel；左右相邻卡是预览，不接收拖动。
- **默认焦点**：优先「进行中」有卡片时聚焦进行中；否则聚焦第一个有卡片的状态；都为空时聚焦「待准备」。状态内默认显示第一张卡。
- 旧群目标卡仍在独立的「目标卡片」区域，不参与任务卡轮播。

## 2. 兼容与边界

- 任务账本、调度器、独立验收、Release 门禁、proposal 规则均未改动；`ready` 仍显示在「等待中」状态。
- 列头部、重命名、左右移动列、归档全部、加卡、快捷添加、列内排序偏好均保留。
- 焦点状态和卡索引只保存在当前看板会话内，刷新后按默认规则重新选择。
- 窄屏下以中心卡为主（约 86vw），左右卡仅在空间允许时露出边缘；卡片详情仍在独立弹窗中滚动查看。
